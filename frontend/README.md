# Job Board Connect

I'm building the frontend for a job portal app called JobPortal.

Use React + Tailwind CSS. Set up React Router with these routes to start:

/, /login, /register, /jobs, /jobs/:id

The app has two user roles: "candidate" and "employer". After login, candidates

and employers see different navigation/dashboards, so structure the app with

that in mind from the start (e.g. a role check that swaps the nav links).

Use a clean, modern look — light background, one accent color, card-based

layout for lists. Don't wire up any real API yet — use local mock data for

everything until I tell you otherwise.
